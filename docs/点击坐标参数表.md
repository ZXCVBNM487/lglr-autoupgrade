# 点击坐标参数总表

> 本文把 `lagrange_upgrade.py` 里**散落各处的点击坐标 / OCR 区域 / 判定阈值**
> 与 `config.example.json` 的配置项集中到一处，供校准、排错与二次开发查阅。
>
> 最近一次 adb 实测：**2026-11-06 19:05–19:15**（星图主界面 + 活动弹窗，2310×1080）。
> 实测截图见 [`screenshots/`](screenshots/)（`starmap.png` 原图、`starmap_grid.png` 带 100px 网格，均已脱敏）。

---

## 0. 三条铁律（改任何参数前先读）

1. **所有坐标都是「设计基准 2310×1080」下的值**，必须经 `scale_box(adb, box)` 按
   `adb.w / DESIGN_W`、`adb.h / DESIGN_H` 等比换算后才能用于点击 / 裁剪。
   禁止把像素写死到设备坐标（`lagrange_upgrade.py:214` 定义 `DESIGN_W, DESIGN_H = 2310, 1080`）。
2. **能靠 OCR 文字找按钮就别靠坐标**：`find_button()` / `find_close_x()` 模板识别是首选，
   坐标只作兜底。坐标兜底一律带日志 `warn`，便于事后发现偏移。
3. **有两处坐标是禁区**：
   - 基地建设页右上 `(1879~1915, 67~69)` 是**直播挂件**，不是「一键升级」——
     代码里 `_AU_ONKEY_BTN_DEPRECATED = (1915, 69)` 仅作历史记录，**永不点击**。
   - 不要用系统返回键 `keyevent 4`，游戏会弹「确定要退出游戏」；误弹时靠
     `_AU_EXIT_CANCEL = (1495, 700)` 点「取消」。

## 4. 校准方法（下次接上设备照做）

```bash
# 1) 全屏 OCR + 画框标注（会把 §1/§2 的框和点画到图上）
python lagrange_upgrade.py scan

# 2) 单张截图
python lagrange_upgrade.py shot        # 输出 shot.png

# 3) 手工量坐标：把截图叠 100px 网格（docs/screenshots/starmap_grid.png 就是这么来的）
#    读出的坐标 → 填进 config.json 的 btn_box / popup.close_box → 重跑 scan 复核
```

`scan` 会在图上画出：各 OCR 区域框、升级按钮兜底点、退出框取消点、面板 X 兜底点，
是校准 `btn_box` 那组**早期遗留区域**最直接的办法。
